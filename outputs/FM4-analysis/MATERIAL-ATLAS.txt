ATLAS MATERIAL FM4 - 16 Oktober 2026
===================================
Peta shader adegan FM4 ke material game: dasar untuk mod shader material
(cat mobil, kaca, aspal) dan pass baru, gaya Custom Shaders Patch. Ringkasan
ini hanya memuat nama dan register dari tabel konstanta game, bukan kode;
atlas lengkap dibuat dari data milik pengguna dan tetap di BuildRoot.

CARA MEMBUAT
------------
outputs/FM4-build/e2e/material_atlas.py --build-root <BuildRoot> --dump
<dump_shaders dir> [--inventory <REX_GPU_INVENTORY json>] --json
<BuildRoot>\atlas\atlas.json
- Sumber container shader (sama dengan katalog post-process B4): Media\Shaders
  (.fxobj mobil, efek partikel), default.xex (loaded-image.bin), dan shader
  material lintasan di Media\tracks\<lintasan>\bin.zip. Entri bin.zip memakai
  metode zip 21: XMemCompress LZX, frame [FF + ukuran asli] + ukuran blok,
  window 128 KB; didekompresi dengan lzx_decompress milik runtime
  (rexruntime.dll, diekspor), CRC zip cocok. 32 lintasan, 1.132 file, 235
  template material (ROAD_*, RDEDG, RDLINE, SHLDR, TERR, TREE, TREECARD,
  GRASS, SKY, SIGN, BARR_SHAD, LAKE/RIVER/OCEAN, ANIM_*, ...).
- Pixel shader dicocokkan lewat md5 ucode (big-endian). Vertex shader tidak
  bisa: Direct3D milik game menambal instruksi vfetch VS untuk vertex
  declaration saat bind, jadi ucode di memori berbeda dari file (64 byte
  pertama sama). VS dicocokkan ke container dengan panjang sama dan dword
  sama terbanyak (ambang 75%).
- Kelas: shader lintasan dari prefiks nama file, shader mobil dari nama
  konstanta/sampler (GlassColor -> glass, Chrome* -> chrome, PaintScale ->
  paint, ...), VS dari pixel shader pasangannya yang paling banyak draw.

Jumlah draw bukan luas layar: aspal dan langit sedikit draw tetapi menutup
sebagian besar layar.

CAT BODI MOBIL (target pertama mod material)
-------------------------------------------
PS B85EF04779ABD438 (106 ribu draw di sampel; VS 8D05A46C3584CA9E, sumber
shaders_v16 dan shaders_splitscreen_v16). Sampler (s# = texture fetch):
  baseSampler s0, damageSampler s1, DirtSampler s2, DirtMaskSampler s3,
  envBackgroundSampler s4 (2D), envSampler s5 (cube dinamis),
  envStaticSampler s6 (cube statis), trackLightmapSampler s10,
  s_varianceShadowMap s13 (self-shadow).
Konstanta PS: psLightDirWS c43, shDirectionalColour c42, psFogColor c47,
  reflectionScaler c52, alphaDirtAmount c57, c_eyePosWS c59,
  trackLightMapParams c60, ShadowDarkeningRamp c80, MinDiffuse c81,
  PaintColor c83, PaintScale c84, Stripe* c85-c87, SpecularAmount2/Power2
  c88-c89, SpecularAmount3/Power3 c90-c91, DynamicEnvLightmapDampner c92,
  FresnelIndex c93, FresnelScalar c94, Dirt/Damage*Kill c95-c97, TwoTone*
  c98-c101, SHBTransition* c102-c103, Metal* c104-c107, MinShadowValue
  c108, StaticEnvSH* c109-c110; bool doselfshadow b0, premultipliedAlpha b1,
  useStaticCubeMap b2, specular2Everywhere b3, psUseBackgroundMap b5,
  psIsStockRaceCar b6.
Interpolator (dibaca dari ucode VS dengan tabel konstantanya: matWVP c0,
matWV c4, matW c8, matWInvT c12, trackLightmapWVPS c32, SH c36-c40,
c_shadowTexMtxNear c48):
  r0  UV (uv1CompressionFactors) dan UV kotoran (DirtOffsetU/V)
  r1  normal dunia (matWInvT, dinormalisasi)
  r2  posisi dunia (matW); W: suku SH directional
  r3  koordinat shadow map (c_shadowTexMtxNear)
  r4  UV lightmap lintasan (trackLightmapWVPS)
  r5  ambient SH RGB (shHemisphericalLightR/G/B); W: shCubeMapDampnerLight
Jadi normal, posisi dunia, posisi mata, arah matahari, cube env, shadow dan
ambient sudah ada di pixel shader: shading cat baru (clearcoat GGX, fresnel,
flake) tidak butuh override vertex shader. Varian cat lain (E5B1A71249D0CA9A
tanpa env cube, 46CB671D893E6709, AB9B5568DBC34C8F, 74FE953B234A69E6) dan
velg memakai blok register yang mirip (c80 ke atas per material, c40-c60
bersama).

  dan A4A965C189287B99 (tanpa sumber, point/rect).
